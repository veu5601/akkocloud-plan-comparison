## “托管”和“租用”是两件事，买错方向就白花钱

Colocation 的意思是机器是你的，服务商提供机房位置、电力、网络、制冷和驻场人手。机器里的操作系统、软件、代码、安全补丁全归你自己管，服务商不碰你的系统，也通常不帮你装环境。这种模式适合已经有硬件资产、机箱规格固定、或者必须物理独占一台机器的业务。

租用是另一回事。你付的钱买的是虚拟机或整机使用权，开机后给你 IP 和 root 密码，环境自己装，但硬件故障、网络中断、机房电力这些不归你操心。

## 三条只写在规则里的限制

**不退款，只退余额。** 上面已经说过，这一条决定了你的试错成本。支付宝付出去的钱，退回账户余额和退回银行卡是两码事。

**工单不是 7×24 即时响应。** 官网公告写明上班时间为上午十二点到晚上十点，工作时间内提交的问题 24 小时内答复、48 小时内解决，非工作时间由值班人员尽快答复。这个响应速度和宣传“7×24 技术响应”的商家不在一个量级，半夜三点线路挂了，大概率要等到第二天中午。跑生产业务的话，把这一条算进风险评估。

**备份自理。** 这类低价 VPS 的通行做法是不对客户数据负责，快照、异地备份要你自己做。10GB 硬盘装完系统剩不了多少，重要数据别只放一份在机器上。

对照一下同类条款会更清楚代价在哪。有服务商的海外云报价不含税，开发票加收 8%，新开首月可月付但续费必须按季度起付；还有商家写明被攻击的用户视为滥用网络行为，停机处理且费用不退。买之前把条款页翻一遍，比看首页 banner 有用。

## 线路参数怎么读：300Mbps 和 500Mbps 不是你能跑到的速度

**CN2 GIA 说的是回程。** 中国电信的 CN2 网络里 GIA 是最高一档，回国路由直连、拥堵少。但它通常只保证回程方向，去程可能走普通线路。对建站、API、远程桌面这类下行流量为主的需求，回程质量就是体验的关键；反过来你如果主要往外推数据，得单独问去程。

**端口带宽是上限，不是单线程速度。** 一份 2025 年 6 月针对伦敦 512MB 实例的第三方测试报告里，标称 500Mbps 的机器，单线程 TCP 跑本地都到不了 500Mbps 的峰值，回国单线程只有 100Mbps 量级。想真正吃满端口，靠多线程并发或者 CDN，单线程下载别按标称值预期。

**IP 归属地要问清楚。** 同一份测试里，伦敦机房的实例查出来的 IP 归属显示为美国广播 IP。做英国本地搜索排名、当地支付通道、广告账户审核这类需要“看起来像当地人”的业务，下单前先问 IP 段注册地。跨境电商和社交账号运营对这点尤其敏感。

**原生 IP 的判断标准**是 IP 的注册归属地和机房所在地一致、没有经过二次分配或多次跳转。这个概念被商家用得很泛，最好让客服给出你将要拿到的 IP 段，自己查一遍再付钱。

**IP 被封和处理边界。** 用 ping.pe 或 ping.chinaz.com 做双向测试，国外通、国内不通基本就是被墙。换 IP 对域名被封无效，域名本身进了名单，换多少次 IP 都一样。

## 按用途挑：四种需求对应的配置下限

**个人博客、文档站、静态页。** 512MB 能跑，前提是开 swap、不装重型面板。年付 299 元这一档在这个价位段里没什么对手。

**WordPress 独立站、小外贸站。** 768MB 是底线，1GB 更稳。数据库和 PHP 一起跑，512MB 会频繁 OOM。要是主要客户在欧盟，把节点放法兰克福或伦敦，比放在美西快得多。

**跨境店铺、多账号运营、广告投放。** 这类需求看的不是硬盘多大，而是 IP 干净不干净、能不能加 IP、IP 归属地对不对。AkkoCloud 的 VPS 默认 1 个 IPv4，多 IP 得走独立服务器或者另找站群方案，别指望在 50 元这档解决。

**游戏、金融、API 入口这类容易被攻击的业务。** AkkoCloud 没有高防产品线，官网三类产品里也没有 DDoS 清洗这一项。真要做，得另找高防商家：市面上香港节点 20G DDoS/CC 清洗的报价在 138 美元/月起，新加坡 100M 优化带宽的大带宽机型也是同一价位段。这个钱不能省，普通 VPS 挨一次大流量攻击，基本就是 null route 加停机。

顺带说一个选型上容易忽略的差异。同样是几十块钱，有商家的新加坡云给到 1 核 1GB、10M 端口、不限流量，月付 65 元；AkkoCloud 50 元给的是 512MB、300Mbps 端口、每月 500GB 流量。前者适合长期稳定但流量大的场景（比如持续同步、监控拉流），后者适合突发带宽高、月总量不大的场景（比如网站加载、临时下载）。流量和带宽哪个先撞墙，取决于你的业务形态，不是配置单上的数字大小。

## 500GB 流量到底能撑多久

按一个页面平均 1MB 估算（含图片、CSS、JS），500GB 大约是 50 万次页面访问。一个日 PV 1000 的站，一个月消耗 30GB 左右，离上限很远。真正吃流量的是视频、大文件下载、图片站和 API 的大响应体，这几类业务 500GB 可能一周就见底，页面越重消耗越快，装个统计插件看实际用量比估算靠谱。

超了之后通常限速或者按量计费，具体规则在结算页写明。做下载站、视频点播这类业务，一开始就不该看 512MB 这档，直接上独立服务器。

## 常见问题

**海外服务器需要备案吗？**
服务器放在境外，网站不需要办 ICP 备案，这也是这类产品被叫“免备案服务器”的原因。备案管的是境内接入服务，跟内容合规、域名实名是两回事，别混着理解。

**512MB 内存真的能建站吗？**
静态站、轻量博客可以，WordPress 装上几个插件就吃紧了。数据库、PHP-FPM、Nginx 加起来，512MB 需要靠 swap 撑，硬盘 IO 会被拖慢。省下的钱不如直接上 768MB。

**续费会不会涨价？**
这篇文章只核到当前售价，没有可靠的续费价数据。这家套餐限量补货、促销价随库存变动，续费按下单页账单为准。下单时把发票或订单页截图存好，比事后争论有用。

**被 DDoS 了怎么办？**
普通 VPS 遇到攻击，商家的常规操作是封 IP 或者停机止损，有的条款直接把被攻击视为滥用、费用不退。做易招攻击的业务，从第一天就该买高防，而不是等挨打了再换。

**能不能先试用？**
没有公开的免费试用。最低成本的试法是买一周或一个月的季付、月付套餐，跑完晚高峰再决定要不要年付。

**能装 Windows 吗？**
公开信息里这些套餐给的系统是 Linux 发行版，512MB 内存本身也跑不动 Windows。需要 Windows 环境的话，下单前直接问客服。
